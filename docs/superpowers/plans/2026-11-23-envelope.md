# Envelope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Android app that explains UK official letters, with Gemini Nano stripping personal details on-device before the cloud model reasons over the letter, plus a privacy receipt proving what left the phone.

**Architecture:** Single `:app` module. Pure-Kotlin `privacy/` core (pattern redaction, merge, leak guard, restore) unit tested on JVM. `ai/` wraps three Firebase AI Logic hybrid `GenerativeModel`s behind a `TextModel` interface so the `pipeline/` is testable with fakes. Compose UI with ViewModels and Navigation; manual DI via `AppContainer`.

**Tech Stack:** Kotlin, Jetpack Compose + Material 3, Navigation Compose, kotlinx.serialization, coroutines, Room (KSP), Firebase AI Logic (hybrid), App Check, Anonymous Auth, Firestore, Remote Config, ML Kit (Document Scanner, Text Recognition v2, Entity Extraction), JUnit4 + kotlinx-coroutines-test.

**Spec:** `docs/superpowers/specs/2026-11-23-envelope-design.md`

## Global Constraints

- Package `dev.novanest.envelope`; `minSdk = 26`; compileSdk/targetSdk stay at 37.
- `com.google.firebase:firebase-ai:18.2.0` and `com.google.firebase:firebase-ai-ondevice:16.0.0-beta08` pinned explicitly (on-device not in BoM). Other Firebase libs via the latest Firebase BoM.
- On-device code annotated `@OptIn(PublicPreviewAPI::class)`.
- Redaction model calls use `InferenceMode.ONLY_ON_DEVICE`; quick check `InferenceMode.PREFER_ON_DEVICE`; explain `InferenceMode.ONLY_IN_CLOUD`.
- Every cloud model call and every Firestore write passes through `LeakGuard.assertSafeToSend`. No exceptions.
- Token maps are never sent to cloud or Firestore; stored only in Room; excluded from backup and device transfer.
- Token format exactly `[TYPE_N]`, `TYPE` ∈ `NAME, ADDRESS, POSTCODE, NI_NUMBER, ACCOUNT, REFERENCE, PHONE, EMAIL, DOB`, N from 1 per type in order of first appearance.
- Dates (except labelled DOB), money amounts and organisation names are **not** redacted.
- Default cloud model `gemini-3.8-flash`; overridable via Remote Config key `cloud_model_name`.
- Remote Config keys: `cloud_model_name`, `redaction_patterns_json`, `prompt_redact`, `prompt_quickcheck`, `prompt_explain`, `nano_chunk_words` (default `2500`). All have bundled defaults.
- Firestore path `users/{uid}/letters/{letterId}`.
- All sample letters use fictional names, addresses and numbers.
- Repo: Apache-2.0 `LICENSE` at root.
- `google-services` Gradle plugin applied only when `app/google-services.json` exists, so the project builds and unit tests run before Firebase is set up.

## Review Focus

1. **Name split across OCR line break** ("Margaret\nO'Neill") — merger matches values with any whitespace run between words. Test in Task 3.
2. **Short name inside another word** ("Ann" in "Annual", "Annex") — replacement only at word boundaries. Test in Task 3.
3. **Sort code vs date** (`12-04-26` in "Date: 12-04-26") — sort code pattern requires a "sort code" label within 20 chars before it. Test in Task 2.
4. **Model returns JSON wrapped in ```json fences or with prose around it** — `ModelJson.decode` extracts the first `{…}` block; parse failure surfaces as a typed error, not a crash. Test in Task 5.
5. **Blank or near-empty OCR** (photo of a table, < 40 chars) — pipeline stops with `PipelineError.NotALetter` before any model call. Test in Task 8.
