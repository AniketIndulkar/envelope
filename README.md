# Envelope

Photograph a confusing official letter (HMRC, council, NHS, bank, landlord) and Envelope tells you what it means, what to do and by when, and drafts a reply. Gemini Nano strips your personal details **on the phone** before the cloud model ever sees the letter; your details are put back into the answer on-device. A privacy receipt shows exactly what left the phone.

Built with the Firebase AI Logic hybrid inference SDK for #BuildHybridAI 2026.
